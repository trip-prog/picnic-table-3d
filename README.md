# Picnic table: 3D preview

Interactive browser preview of a photo-based table model. Drag to rotate, scroll or pinch to zoom. No installation or login is required.

The model, textures, and viewer are embedded in `index.html`. GitHub Pages serves the root of the `main` branch.

The optimized model has 40,220 triangles (down from 124,156), retaining all 206 components. Sampled bidirectional surface comparison found a maximum deviation of approximately 0.194 mm relative to the original photo reconstruction. This is not a manufacturing tolerance.

Downloads: `picnic_table_mm.stl` contains the full assembly in millimetres; `picnic_table_parts_mm.zip` contains 206 individually named STL files, a component inventory, and preparation notes. Read `manufacturing_notes.txt` before using the files for production planning.

Dimensions and hidden construction are approximate. This is a visual reconstruction, not a manufacturing drawing.

Viewer: [Google model-viewer](https://modelviewer.dev/) 4.3.1; license notices are embedded in the HTML. Wood material: [Poly Haven Wood Table 001](https://polyhaven.com/a/wood_table_001), CC0.
