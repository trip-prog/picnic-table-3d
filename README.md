# Picnic table: 3D preview

Interactive browser preview of a picnic table concept. The AI-generated reference guides the overall appearance; the connections have been deliberately redesigned. Drag to rotate, scroll or pinch to zoom. No installation or login is required.

The model, textures, and viewer are embedded in `index.html`. GitHub Pages serves the root of the `main` branch.

The revised model has 76,206 triangles and 260 closed components. Ornamental leg bolts, splice plates and ground projections have been removed. The frame is conceived as welded. All 21 boards have two through-bolts each to actual steel supports, with underside washers and nuts. Seat bearers stop at the two brackets they connect. Surface-intersection and fastener-clearance checks pass. Use the hardware close-up button to inspect the connections from below.

Downloads: `picnic_table_mm.stl` contains the full assembly in millimetres; `picnic_table_parts_mm.zip` contains 260 individually named STL files, a component inventory linking hardware to its connected parts, and preparation notes. Read `manufacturing_notes.txt` before using the files for production planning.

Dimensions are provisional. Threads, tube wall thicknesses, weld specifications and load calculations are not defined. This is a construction concept, not a manufacturing drawing.

Viewer: [Google model-viewer](https://modelviewer.dev/) 4.3.1; license notices are embedded in the HTML. Wood material: [Poly Haven Wood Table 001](https://polyhaven.com/a/wood_table_001), CC0.
