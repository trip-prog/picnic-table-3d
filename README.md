# Picnic table: 3D preview

Interactive browser preview of a photo-based table model. Drag to rotate, scroll or pinch to zoom. No installation or login is required.

The model, textures, and viewer are embedded in `index.html`. GitHub Pages serves the root of the `main` branch.

The revised model has 74,372 triangles and 202 closed components. Clean mitred profiles, eight open timber brackets, smooth surfaces, and regular hex fasteners replace the previous overlapping and deformed details. The timber/frame surface-intersection check passes. Use the hardware close-up button to inspect the connections.

Downloads: `picnic_table_mm.stl` contains the full assembly in millimetres; `picnic_table_parts_mm.zip` contains 202 individually named STL files, a component inventory, and preparation notes. Read `manufacturing_notes.txt` before using the files for production planning.

Dimensions and hidden construction are approximate. This is a visual reconstruction, not a manufacturing drawing.

Viewer: [Google model-viewer](https://modelviewer.dev/) 4.3.1; license notices are embedded in the HTML. Wood material: [Poly Haven Wood Table 001](https://polyhaven.com/a/wood_table_001), CC0.
